A chess engine that fits in 4 KB of Python (4,052 bytes, standard library only). PeSTO tapered evaluation with midgame/endgame piece-square tables, PVS search with a transposition table, null-move pruning, late-move reductions, check extensions and quiescence. Deterministic and node-budgeted. Local kit gauntlet: Elo 1654 and 1809 across two trials (the previous version scored 1545/1545). The readable source is engine.py; main.py is its packed form.

## Run it

```sh
python3 main.py
```
